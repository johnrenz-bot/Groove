## `app/` — Pages & Routes

The `app/` directory uses **Next.js App Router** conventions.
Directories in parentheses `(client)`, `(coach)` are **route groups** — they provide
shared layouts without adding a URL segment.

```text
app/
├── layout.tsx                      # Root layout: HTML shell, ThemeProvider, PresenceBridge
├── globals.css                     # Master CSS: design tokens, dark/light themes, utilities
├── loading.tsx                     # Root Suspense boundary (brand loading screen)
├── page.tsx                        # / — Public landing page (dark-mode only)
│
├── (client)/                       # Route group for client portal
│   └── client/
│       ├── layout.tsx              # Wraps children in ClientLayout
│       ├── home/page.tsx           # /client/home — Dashboard with trending coaches
│       ├── appointments/page.tsx   # /client/appointments — Booking management
│       ├── calendar/page.tsx       # /client/calendar — Calendar view
│       ├── profile/page.tsx        # /client/profile — Own profile + portfolio
│       ├── talent/page.tsx         # /client/talent — Browse/book coaches
│       ├── about/page.tsx          # /client/about — About the platform
│       └── settings/page.tsx       # /client/settings — Account settings
│
├── (coach)/                        # Route group for coach portal
│   └── coach/
│       ├── layout.tsx              # Wraps children in CoachLayout
│       ├── home/page.tsx           # /coach/home — Dashboard with upcoming sessions
│       ├── appointments/page.tsx   # /coach/appointments — Manage incoming bookings
│       ├── calendar/page.tsx       # /coach/calendar — Schedule calendar
│       ├── profile/
│       │   ├── page.tsx            # /coach/profile — Own profile + portfolio
│       │   └── edit/page.tsx       # /coach/profile/edit — Profile editor
│       ├── talent/page.tsx         # /coach/talent — Browse coaches (peer view)
│       ├── talents/page.tsx        # /coach/talents — Talent discovery page
│       ├── about/page.tsx          # /coach/about — About the platform
│       └── settings/page.tsx       # /coach/settings — Account settings
│
├── admin/                          # Admin console (server-guarded)
│   ├── layout.tsx                  # Server layout: verifies admin identity, redirects others
│   ├── dashboard/page.tsx          # /admin/dashboard — Metrics, charts, activity log
│   ├── users/page.tsx              # /admin/users — Full user directory
│   ├── clients/page.tsx            # /admin/clients — Client-only user list
│   ├── coaches/page.tsx            # /admin/coaches — Coach-only user list
│   ├── bookings/page.tsx           # /admin/bookings — All platform bookings
│   ├── transactions/page.tsx       # /admin/transactions — Transaction ledger
│   ├── verifications/page.tsx      # /admin/verifications — Document review queue
│   ├── messages/page.tsx           # /admin/messages — Admin ↔ user messenger
│   ├── inquiries/page.tsx          # /admin/inquiries — Support ticket triage
│   ├── announcements/page.tsx      # /admin/announcements — Broadcast manager
│   ├── maintenance/page.tsx        # /admin/maintenance — Maintenance notices
│   ├── settings/page.tsx           # /admin/settings — Platform configuration
│   ├── control/page.tsx            # /admin/control — Advanced control panel
│   ├── theme/page.tsx              # /admin/theme — Theme accent configuration
│   └── verify-passcode/page.tsx    # /admin/verify-passcode — Admin 2FA passcode
│
├── api/                            # Server Route Handlers
│   ├── ai/
│   │   └── coach-assistant/route.ts  # POST — DeepSeek AI assistant
│   ├── admin/
│   │   ├── audit/route.ts            # GET — Admin audit log
│   │   └── users/route.ts           # GET/PATCH — Admin user management
│   ├── dance-events/route.ts        # GET — External dance events feed
│   ├── studios/route.ts             # GET — OpenStreetMap studio locator
│   └── tickets/route.ts             # POST — Public support ticket submission
│
├── auth/
│   └── callback/route.ts           # OAuth callback (exchanges code for session)
│
├── login/page.tsx                  # /login — Unified sign-in (dark-only)
├── register/
│   ├── client/page.tsx             # /register/client — Client registration wizard
│   ├── coach/page.tsx              # /register/coach — Coach registration wizard
│   └── complete/page.tsx           # /register/complete — Registration success
│
├── forgot-password/page.tsx        # /forgot-password — Password recovery
├── reset-password/page.tsx         # /reset-password — Token-based password reset
│
├── messages/page.tsx               # /messages — Direct messaging (shared route)
├── contracts/
│   └── [id]/page.tsx               # /contracts/:id — Agreement view/sign
├── dance-events/page.tsx           # /dance-events — External events feed
├── userprofile/
│   └── [id]/page.tsx               # /userprofile/:id — Public profile viewer
│
├── terms/page.tsx                  # /terms — Terms of Service
├── privacy/page.tsx                # /privacy — Privacy Policy
│
```
